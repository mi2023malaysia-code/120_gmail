Google OAuth 2.0 Credentials Setup
How to get your Client ID:
1
Go to the Google Cloud Console, create a project, and enable the Gmail API under APIs & Services.
2
Under OAuth Consent Screen, set User Type to External or Internal, add scopes: gmail.readonly, gmail.send, gmail.modify.
3
Go to Credentials → Create Credentials → OAuth Client ID (Web application). Add Authorized JavaScript origin: http://127.0.0.1:5173 (or http://localhost:5173).
